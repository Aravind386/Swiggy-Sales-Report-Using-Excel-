
# 🍊 Swiggy Sales Analysis Dashboard using Microsoft Excel

### 📊 Sales Performance | Customer Ratings | Restaurant & Food Category Analysis

An interactive sales analysis dashboard created using Microsoft Excel to analyse Swiggy's sales performance, customer ratings, order trends, food categories, restaurant performance, and state-wise sales distribution.

---

## 📌 Project Overview

The Swiggy Sales Analysis Dashboard provides a consolidated view of sales and order performance through key performance indicators (KPIs), charts, tables, and interactive filters.

The dashboard helps explore monthly sales trends, daily ordering patterns, food category contributions, customer ratings, restaurant performance, and geographical sales distribution.

This project demonstrates how Excel dashboards can transform raw sales data into meaningful business insights for reporting and decision-making.

---

## 🎯 Project Objectives

- Analyse total sales and order performance.
- Monitor average customer ratings and rating counts.
- Identify monthly and daily sales trends.
- Compare sales across food categories.
- Analyse state-wise and city-wise sales performance.
- Evaluate restaurant and product-level performance.
- Compare quarterly sales, ratings, and order volumes.
- Build an interactive dashboard for business reporting.
